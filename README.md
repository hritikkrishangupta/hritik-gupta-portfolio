# Portfolio Website

## How to Run

Double-click `start-portfolio.bat`, then open:

```text
http://127.0.0.1:5500
```

Do not open `index.html` directly if you want the JSON data to load. Browsers block JavaScript from reading external JSON files on `file://` pages.

## Editable Data Files

Update these files to change the website content:

- `data/projects.json`
- `data/experience.json`
- `data/skills.json`

After editing a JSON file, refresh the browser.
